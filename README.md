# Flaxa – Mac-appen

Nedladdningar av Mac-appen för **Flaxa**, Flappy Bird-spelet från Klockspel gjort för datorn.

- **Spela på webben:** https://appstugan.up.railway.app/flaxa/
- **Ladda ner:** se [senaste release](https://github.com/Ville132/flaxa-releases/releases/latest).
  `Flaxa.dmg` är för Apple Silicon (M1 och senare), `Flaxa-Intel.dmg` för Intel-Macar.

Installera: dubbelklicka på DMG-filen och dra `Flaxa` till `Applications`. Appen är inte signerad med ett
Apple-utvecklarkonto, så första gången: klicka *Klar*, öppna *Systeminställningar → Integritet och säkerhet* och välj
*Öppna ändå*.

Appen visar alltid samma version som webbplatsen och fungerar även utan internet. Det här repot innehåller bara
nedladdningarna; källkoden är privat.
